# MedFlow AI

An AI-Native Hospital Management Platform built with Laravel, React, and OpenAI.

## Tech Stack

- Laravel 12
- React
- Tailwind CSS
- MySQL
- OpenAI Responses API
- Tool Calling
- AI Agents

## Modules

- Authentication
- Dashboard
- Patient Management
- Appointments
- Medical Records
- AI Assistant
- Prescriptions
- Reports
